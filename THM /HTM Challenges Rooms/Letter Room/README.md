TryHackMe – Letter Room (Write-up)

In this room, I was given an envelope, a newspaper clipping, and a note. At first, it was a bit confusing, especially because the postal code on the envelope was not clearly visible.

From the envelope, I understood that it was from France. The postal code was not written normally, it looked like a pattern, so I had to zoom in and look carefully to understand it.

The newspaper clipping gave a clue about an event, and the note mentioned things like “great-grandfather” and “youngest.” Using these clues, I was able to search and find the correct person.

After finding the person, I got the name and age from the article and used them to create the final flag.

What I learned:

- Pay attention to small details
- Don’t guess, always verify
- Combine clues and think logically

It was a simple room, but good for practicing OSINT thinking
