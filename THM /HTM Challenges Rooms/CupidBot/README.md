CupidBot (Write-up)

In this task, I interacted with a chatbot and used prompt injection to trick it. At first, the bot refused to give any hidden data, but it leaked a verification code. I used that code in different prompts to bypass restrictions.

By changing the wording and using commands like “ignore instructions” and “debug mode”, I was able to make the bot reveal hidden information. This helped me get the prompt injection flag first, and then the other flags.

This task taught me how attackers can manipulate AI systems using carefully crafted prompts and how small leaks can be used to get more sensitive data.
