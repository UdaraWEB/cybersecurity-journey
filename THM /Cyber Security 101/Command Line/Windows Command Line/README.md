Command Line ( Writeup )

In this room, I learned the basics of using the Windows Command Line (CMD). At the beginning, I understood how to get basic system information using commands like "ver" and "systeminfo". This helped me see details about the operating system and the machine.

Then I learned how to troubleshoot network issues using simple commands. This showed me how to check connectivity and understand network settings.

After that, I practiced working with files and directories. I used commands like "dir" to list files, "cd" to move between folders, "mkdir" to create folders, and "rmdir" or "del" to remove them. I also learned how to read file contents using the "type" command.

Next, I learned about managing running processes. I used "tasklist" to view running programs and "taskkill" to stop them using a PID. I also understood how to filter results using "/FI".

Finally, I learned some useful system commands like shutting down or restarting a computer using "shutdown", and how to cancel it using "shutdown /a".

Overall, this room helped me understand how powerful the Windows Command Line is. Now I can navigate the system, manage files, check processes, and perform basic system tasks without using the graphical interface.
